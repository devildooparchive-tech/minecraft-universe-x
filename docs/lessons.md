# Lessons Learned — دروس وأخطاء مسجلة

> يسجل هنا أي درس قابل لإعادة الاستخدام أثناء التطوير. المراجعة قبل بدء كل مرحلة.

## Phase 0 — 2026-08-24

| # | الدرس | التصنيف |
|---|---|---|
| L1 | مجلد المشروع قد يكون "مشغولًا" بعمليات vite dev server قديمة من جلسات سابقة — افحص `wmic process` قبل أي عملية نقل/حذف، وأوقف العمليات أولًا. | بيئة Windows |
| L2 | في git-bash على Windows: `taskkill //F` يفشل في ترجمة المسارات أحيانًا؛ الصيغة الموثوقة `/F /PID x`. | بيئة Windows |
| L3 | v1 كان بلا Git نهائيًا — أي مشروع جديد يبدأ بـ `git init` قبل كتابة أول سطر كود. | عملية |
| L4 | بيانات المحتوى داخل الكود (registry.ts في v1) تجعل التعديل يتطلب إعادة بناء — كل المحتوى في v2 يعيش في JSON. | معمارية |
| L5 | `cd` داخل مجلد ثم `mv` عليه يفشل بـ "Device or resource busy" حتى بعد `cd ~` في نفس الاستدعاء — غيّر cwd الدائم للجلسة أولًا. | بيئة Windows |
